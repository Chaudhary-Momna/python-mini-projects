# 🐍 Python Mini Projects

This repository contains a collection of Python command-line applications built to demonstrate fundamental programming concepts like Object-Oriented Programming (OOP), File Handling, and Data Validation.

## 📂 Projects Included

### 1. 🏧 Bank ATM System (`atm_system.py`)
- **Concepts Used:** Object-Oriented Programming (Classes, Objects), Encapsulation (Private attributes), Conditional Logic.
- **Features:** Account creation, PIN verification, Deposit, Withdraw, and Balance check with error handling.

### 2. 🎓 Grade Calculator (`grade_calculator.py`)
- **Concepts Used:** Functions, Loops, Exception Handling (`try/except`).
- **Features:** Takes student scores as input, calculates the class average, and assigns grades (A-F) based on the score.

### 3. 🔐 Smart Password Vault (`password_vault.py`)
- **Concepts Used:** File Handling (Read/Write), OS module, String manipulation.
- **Features:** Secures passwords behind a Master Password. Generates random secure passwords and saves them to a local text file.

### 4. 🌡️ Temperature Converter (`temperature_converter.py`)
- **Concepts Used:** Mathematical operations, User Input, Error Handling.
- **Features:** Converts temperatures between Celsius, Fahrenheit, and Kelvin.
